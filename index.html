TabImpute

One Pipeline, Many Transformers: Pattern-Specific Imputation Specialists for Tabular Missing Data

A single pre-training pipeline that turns synthetic data into transformer imputers. The default TabImpute model is robust across every missingness pattern we tested. Swap one module, and the same pipeline builds a specialist for the pattern you expect.

How it works

TabImpute follows the prior-data fitted network (PFN) recipe behind TabPFN: generate millions of synthetic problems, and train one transformer to solve them in context. Three pieces make it work for imputation.

1 · Entry-wise featurization

Imputation is recast as supervised prediction. For a table with m rows and n columns, every entry (i, j) becomes one row of a new feature table:

(i, j) ↦ i ⊕ j ⊕ Xi,: ⊕ X:,j  →  target Xij

That gives mn rows with m + n + 2 features. Observed entries are the training points and missing entries are the queries. Features are built from the incomplete table, never the true values.

  • Parallel: all missing entries are predicted in one pass on a GPU.
  • Missing inputs: NaNs in the features are replaced with the column mean, plus a binary indicator of which values were missing.
  • Trade-off: the table grows to mn rows, which suits small and medium tables. Our follow-up, MatrixFormer, works on the matrix directly to scale further.

2 · A TabPFN-style transformer without the query mask

The architecture follows TabPFN v2: attention alternates between features within a row and samples within a feature. One change matters for imputation. TabPFN masks attention between query points, encoding the assumption that test points are independent. Missing entries are not independent, especially when missingness is not at random, so TabImpute removes that mask and lets queries share information. The output is a Riemann (bar) distribution over values, trained with negative log-likelihood.

3 · Synthetic data with an interchangeable missingness module

Data: complete tables come from linear factor models, Y = UVᵀ, with low rank k and latent vectors drawn from Gaussian, Laplace or Student-t distributions. A nonlinear factor model scored almost as well in ablations.

Missingness: a mask is then applied by a pluggable module: MCAR, column-wise MAR, or any of nine MNAR generators (see MissBench). This module is the only part that changes between specialists.

Why train the default on MCAR only? Training on patterns one after another caused catastrophic forgetting, and mixing MCAR, Col-MAR and Self-MNAR made the model fixate on Self-MNAR. Pure MCAR exposes the model to a huge variety of masks that overlap with those of structured patterns. Because the model learns the data distribution given what is observed, not the missingness mechanism itself, this makes a robust general-purpose imputer.

Quickstart

Install from PyPI. The default TabImpute checkpoint downloads from Hugging Face on first use.

bash
pip install tabimpute
python
import numpy as np
from tabimpute.interface import ImputePFN

imputer = ImputePFN(device="cpu")  # or "cuda"

X = np.random.rand(20, 5)
X[np.random.rand(*X.shape) < 0.2] = np.nan

X_imputed = imputer.impute(X.copy())
  • Input: a 2D NumPy array with np.nan for missing values.
  • Best fit: small and medium tables. Each entry becomes a feature row, so cost grows with rows × columns.
  • GPU recommended. On CPU, a table can take a few minutes.
  • Reproduce the paper: MissBench and every figure and table can be regenerated from the command line; see the benchmark README.

Working with larger matrices? MatrixFormer is our follow-up foundation model for matrix completion. It applies axial attention directly to the matrix instead of featurizing every entry.
